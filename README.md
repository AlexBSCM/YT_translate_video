# YT Translate Video

Оконный менеджер загрузок YouTube (Windows, Tkinter + yt-dlp). Название видео не на русском автоматически переводится и сохраняется в имя файла.

## Возможности

- Очередь загрузок с восстановлением после перезапуска (`queue.json`).
- Монитор буфера обмена: вставленная ссылка YouTube сама попадает в очередь.
- Докачка незавершённых видео через temp-папку (`C:\yt_temp`, можно переопределить в `settings.json` ключом `temp_folder`).
- Выбор качества (1080p/720p/480p/360p/лучшее), запасные клиенты yt-dlp при блокировках.
- Перевод названия на русский через Google Translate / MyMemory (deep-translator).
- Прямые эфиры: откладываются в конец очереди, перепроверяются каждые 5 минут (до 3 часов за запуск), затем переносятся на следующие запуски.
- Статус VPN (WireGuard) и переподключение PORTAL WG для смены IP.
- Индивидуальные cookies: файл `cookies.txt` (авто-поиск на рабочем столе) или cookies Chrome.

## Установка

1. Python 3.10+ (32/64-бит) — во время разработки использовался 3.13.
2. Зависимости:
   ```
   pip install -r requirements.txt
   ```
3. `ffmpeg.exe` — рядом со скриптом (опционально; если его нет, yt-dlp ищет его в PATH).
4. Node.js — опционально, ускоряет обход недавних защит YouTube в yt-dlp.

## Запуск

- `run.bat` — запуск в фоне через `pythonw` (без окна консоли).
- `run.vbs` — то же, заодно скрывает вспышку консоли при старте.

## Файлы данных (рядом со скриптом)

| Файл | Назначение |
|---|---|
| `settings.json` | Все настройки (папка сохранения, качество, прокси, флаги) |
| `queue.json` | Текущая очередь, восстанавливается при старте |
| `downloaded.json` | Журнал скачанных видео (JSONL) |
| `temp_state.json` | Какая связка «качество+аудио» действовала для каждого `.part` |

## Структура (ветка `improvements`)

| Модуль | Ответственность |
|---|---|
| `config.py` | Пути, константы, чтение/запись settings / queue / temp_state |
| `utils.py` | Regex YouTube-ссылок, чистка имён, Node/VPN-проверки |
| `translators.py` | Перевод названия на русский |
| `temp_store.py` | Docачка: prepare/move + подмёт temp-папки |
| `downloader.py` | Обёртка yt-dlp: клиенты, форматы, ретраи |
| `gui.py` | Tkinter-интерфейс и очередь воркера |
| `yt_downloader.py` | Точка входа |
